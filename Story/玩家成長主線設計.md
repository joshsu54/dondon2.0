# 玩家成長主線設計

更新日期：2026-10-24。依據 [使用者需求紀錄](玩家成長與宗門秘境_需求紀錄.md) 整理；本文件為待實作設計。下方標示「建議」的內容尚未由使用者定案。

美術方向已由使用者指定以 Q 版角色為主，先從生圖與建模規劃開始。首期資產數量、沿用清單與第一批角色風格圖見 [Q 版美術規劃 v001](../ArtLibrary/Planning/PlayerJourney_QStyle_v001/README.md)。宗門／秘境的數量與具體美術分類為規劃假設，尚未定案。

後續指示：人物、髮型與服裝停止製作；其他素材繼續。非人物首批為獵物、修煉物品、測靈晶石與洞府模組，成果見 [非人物模型交付](../ArtLibrary/ExpansionBatches/QPlayerStart16/README.md)。人物方案未定，不以舊人物初模作為已採用資產。

## 玩家歷程

創角隨機天賦與靈根 → 共同起始地領取《煉氣訣》 → 在家修煉或外出採藥、狩獵 → 創角後現實經過 10 天（離線照常計時） → 廣場測資質與選擇宗門 → 依資質獲得弟子身分 → 領取洞府與靈田 → 修煉、煉丹、煉器、宗門任務與晉升 → 符合條件時參加輪替秘境。

前期與入宗後皆有自由活動循環，不必將所有玩法排成只能依序完成的一條任務線。

## 創角與前期生活

- 天賦、靈根在創角時產生並保存；廣場鑑定揭露同一份資質，不重新抽取。具體資質在鑑定前的顯示程度尚待決定。
- 每名新角色取得《煉氣訣》，具備在家修煉的入口。
- 外出採集靈藥、獵取低級獵物，出售收穫取得靈石，再購買修煉丹藥、武器與裝備。
- 《煉氣訣》領取與初始物品發放需記錄完成狀態，重登不重複領取。
- 入宗前期提供採集、交易、修煉與低級戰鬥內容；玩家不必用遊玩時數填滿等待期，每日遊玩長短不影響創角後第 10 天的解鎖時間。

## 宗門選拔與晉升

使用者於 2026-10-24 將門檻修改為每名角色創建完成後，現實經過整整 10 天。離線、斷線、暫停與掛機均照常計時，不要求累積在線時數。年齡與世界日夜不能代替此計時。

實作時保存角色創建時間及選拔解鎖時間：`SectSelectionUnlockAtUtc = CharacterCreatedAtUtc + 864000 秒`。建議由伺服器提供並驗證時間；登入與進入選拔介面時，檢查目前時間是否已達解鎖時間。倒數歸零只開放資格，不自動入宗。這是待實作設計，並非現有原型已接入的功能。

| 階段 | 玩家操作與結果 |
| --- | --- |
| 尚未達標 | 持續初期生活；顯示解鎖日期時間與剩餘天／時，不要求玩家在線等待 |
| 達到門檻 | 取得宗門選拔資格及廣場引導，不自動入宗 |
| 離線時達標 | 下次登入立即顯示資格與廣場引導，不重新倒數 |
| 廣場鑑定 | 顯示確切天賦、靈根與資質 |
| 選擇宗門 | 顯示可選宗門及預期入門身分，由玩家選擇 |
| 正式入宗 | 保存宗門與弟子身分，分配個人洞府、床、箱子及靈田 |
| 後續晉升 | 高資質可直接內門；其他玩家從雜役或外門逐步晉升，數值與考核條件待設計 |

建議達標資格持續保留，讓玩家能自行選擇參加時間；選拔是否另有固定場次尚未定案。初始資質影響起點，但必須提供平庸資質玩家實際可達成的晉升路徑。

## 宗門生活與空間

| 空間／系統 | 設計要求 |
| --- | --- |
| 起始地 | 玩家可在共同地點活動；承載人數與分流方式待定 |
| 宗門公共區域 | 共同使用；具體包含哪些設施待列定 |
| 個人洞府 | 公共區域外的個人空間；床與箱子隸屬該玩家，箱內物品需保存 |
| 個人靈田 | 可種植，作物與進度歸屬該玩家；離線生長規則待定 |
| 宗門人數 | 顯示該宗門的玩家人數，不使用 NPC 弟子數替代；總成員數或在線數的口徑待定 |
| 宗門職業 | 玩家可選煉丹、煉器、外出任務等玩法；是否可兼修及配方取得方式待定 |
| 貢獻兌換 | 任務取得貢獻值，再換取修煉資源；貢獻值與靈石分別記帳 |

公共多人區域和私人空間仍屬同一角色的成長歷程。私人空間的資源帶回公共玩法時，需要一致的角色資料與交易校驗；目前的本機存檔不能直接當成已完成的多人服務。

## 秘境活動

- 每日、每週輪替不同秘境，部分限定特定宗門，例如劍宗；其餘宗門名稱與活動清單待設計。
- 每個秘境可設定允許宗門、境界範圍、年齡條件、開放時段及探索時限。沒有的限制應明確標示為不限。
- 入口列出所有條件與不符合原因；真正進入時再次檢查資格。
- 單次探索約一小時；時限內未死亡即可持續探索、尋找機緣。
- 活動開放時段與玩家單次探索倒數是兩個不同規則。採入場後約 60 分鐘，或全場統一結束，尚待確認，不能自行混用。
- 死亡會中止該次持續探索資格；死亡代價、能否重新進入、所得保留、提前撤離、到期結算、掉線重連、組隊與 PvP 規則皆待定。
- 建議使用權威時間保存本次探索的截止時間與結算狀態，避免重連刷新倒數或重複取得獎勵；具體斷線政策仍需先確定。

## 與現有程式的銜接

依本次檢視的 `SectQuest`、`SectAdventure` 與 `SectWorkers` 原始碼：目前具備採藥任務、靈石計數、營地建設、NPC 分工與本機進度保存，可沿用部分互動與提示方式。以下是新增系統的實作拆分建議，不是現有功能清單。

| 新系統 | 需要保存／管理的核心資料 |
| --- | --- |
| 角色與修煉 | 角色識別、隨機資質、鑑定狀態、已學功法、修為、境界、年齡 |
| 選拔解鎖計時 | 角色創建 UTC 時間、創角後第 10 天的解鎖 UTC 時間、已解鎖資格；離線照常經過，重開不得歸零 |
| 物品與交易 | 個人背包、裝備、靈石、物品數量、購買與出售結果 |
| 宗門成員 | 所屬宗門、弟子身分、晉升進度、個人貢獻 |
| 洞府與種植 | 所有者、儲物內容、田地與作物生長狀態 |
| 生產職業 | 配方、材料消耗、製作進度與產出 |
| 秘境活動 | 排程、准入條件、本次探索識別、時間、死亡／結算狀態 |
| 多人服務 | 公共區域同步、成員統計、私人空間歸屬及角色資料一致性 |

建議先做可玩的「創角—修煉—採集／狩獵—交易」循環，再串接選拔與入宗生活，最後加入秘境排程與探索；多人資料歸屬需從第一階段規劃。既有營地經營原型另行保留，是否併入這條主線尚未指定。

## 待實作驗收條件

以下僅為未來驗收清單，尚未執行或通過。

1. 同角色重開後資質一致；《煉氣訣》不重複發放，鑑定不重抽。
2. 創角後現實經過 863,999 秒仍未達標，達 864,000 秒取得資格；全程離線亦應在下次登入時解鎖。存讀檔、重連與重啟不重置解鎖時間，不能藉改本機時鐘繞過正式服的時間驗證。
3. 達標不自動入宗；廣場鑑定、玩家選宗與弟子身分符合規則，平庸資質有可完成的晉升路徑。
4. 採集與狩獵所得可交易；購物、製作、貢獻兌換正確扣款扣料，不重複產出。
5. 入宗居所只發放一次；兩名玩家的箱子、靈田與存檔互不覆蓋；公共區域顯示與互動正確。
6. 宗門人數來自實際玩家成員資料；不將招募的 NPC 計入。
7. 秘境宗門、境界、年齡、排程邊界均正確攔截或放行；存活玩家能在有效時限內持續探索。
8. 依定案後的死亡、到期與斷線規則驗證退出及結算；不能藉重連重置倒數或重複領獎。
